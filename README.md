# Сайт «Жизнь без долгов» — как пользоваться

Сайт статический: чистый HTML и CSS, без конструкторов и CMS. Он быстро грузится и дёшево хостится.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `dist/` | **Готовый сайт.** Именно эту папку загружаешь на хостинг |
| `config.yaml` | Настройки: домен, ссылки на бота и канал, реквизиты, Метрика |
| `content/articles/` | Статьи — по одному файлу `.md` на статью |
| `content/pages/` | О проекте, Контакты, Политика, «Как мы зарабатываем» |
| `data/banks.yaml` | Таблица банков для страницы сравнения |
| `templates/`, `assets/` | Дизайн: шаблоны, стили, скрипты, логотип |
| `build.py` | Сборка сайта из всего этого в `dist/` |
| `indexnow.py` | Сообщает Яндексу о новых страницах — индексация за часы |

## Перед первым запуском

1. Открой `config.yaml` и замени: домен, ссылку на бота, ссылку на канал, почту, реквизиты.
2. В `data/banks.yaml` впиши реальные тарифы банков, с которыми есть договор, партнёрские ссылки, рекламодателя и erid. Поставь `demo: false`. Пока там примеры, страница сравнения закрыта от индексации.
3. Проверь шаблон политики конфиденциальности в `content/pages/politika.md`.
4. Пересобери сайт: `python3 build.py`.

Нужен Python 3 и библиотеки: `pip install markdown pyyaml jinja2`.

## Как добавить статью

1. Скопируй любой файл из `content/articles/` и переименуй.
2. Измени шапку: `slug` (адрес), `title`, `description`, `section`, `updated`, `short` (короткий ответ), `faq`, `sources`.
3. Ниже трёх дефисов — текст статьи в обычной разметке Markdown.
4. Запусти `python3 build.py`, загрузи `dist/` на хостинг, затем `python3 indexnow.py`.

Разделы (`section`): `samozanyatost`, `ip`, `nalogi`, `rko`, `udalenka`, `dolgi`.

Проще всего — присылать мне темы из ядра: я пишу статьи и отдаю обновлённый `dist/`.

## Где разместить

Подойдёт любой хостинг, который отдаёт обычные файлы:

- **Обычный хостинг в РФ** (Beget, Timeweb, REG.RU и подобные): загрузить содержимое `dist/` в папку сайта через файловый менеджер или FTP.
- **Бесплатно**: Cloudflare Pages, Netlify, GitHub Pages — загрузить папку `dist/`.

Обязательно включи HTTPS (на большинстве хостингов это бесплатный сертификат в один клик).

## После публикации

1. Яндекс Вебмастер и Google Search Console: добавить сайт, отправить `https://твой-домен/sitemap.xml`.
2. Запустить `python3 indexnow.py` — Яндекс узнает о всех страницах.
3. Создать счётчик Яндекс Метрики, вписать номер в `config.yaml`, пересобрать. Клики по кнопкам бота, банков и калькулятору уже размечены как цели: `bot`, `bank`, `cta`, `calc`.

## Автопубликация (статьи каждый день без ручной загрузки)

В проекте уже настроена схема: **GitHub → автоматическая сборка → хостинг**.

1. Создай бесплатный аккаунт на GitHub и пустой приватный репозиторий (например, `zhizn-bez-dolgov`).
2. Загрузи туда содержимое этой папки (без `dist/`) или дай доступ Claude — он загрузит сам.
3. В репозитории: Settings → Secrets and variables → Actions → добавь секреты:
   - `FTP_HOST`, `FTP_USER`, `FTP_PASSWORD`, `FTP_DIR` — данные FTP от хостинга (папка сайта, обычно `public_html`);
   - `TG_BOT_TOKEN`, `TG_CHAT_ID` — для анонсов в Telegram: создай бота через @BotFather, сделай его админом канала, `TG_CHAT_ID` = `@biznessnul9`.
4. Готово. Каждое изменение в репозитории (новая статья) → через 1–2 минуты сайт обновлён, Яндекс уведомлён, в Telegram-канале вышел анонс.

Файл схемы — `.github/workflows/deploy.yml`.

## Особенности этого сайта

- **Тест «Подходит ли банкротство»** — на главной и на `/test/podhodit-li-bankrotstvo/`. Логика — в `assets/site.js` (блок «Тест»).
- **Кнопки «Консультация»** ведут на `lead_url` из `config.yaml` — сюда ставится бот или форма партнёра. Цель в Метрике: `lead`, прохождение теста — `quiz_done`.
- **Реквизиты партнёра** (`partner_line`) подставляются в «Как мы зарабатываем» и «Согласие на передачу данных» — без согласия заявки партнёру передавать нельзя.
- Каналы в подвале сейчас ведут на каналы «Бизнес с нуля» — если заведёшь отдельный канал про долги, поменяй `tg_url` и `max_url`.
